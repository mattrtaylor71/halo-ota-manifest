# HALO release workflow

Use [AGENTS.md](AGENTS.md), [the frozen 158 handoff](docs/FROZEN_RELEASE_158.md), and `current_baseline` in [RELEASE_BASELINE.json](RELEASE_BASELINE.json). Start future work from frozen `halo-v6.4.158` or reviewed descendants; historical qualification records do not select the current source. Production release builds use the committed snapshot preparer and canonical builder documented in [Production OTA build](docs/OTA_POLICY_PRODUCTION_BUILD.md). Direct Arduino commands without the declared durable-policy profile are compatibility builds, not release artifacts. `halo_ota_demo/publish_both.sh` delegates to the verified prebuilt-artifact publisher. Preserve actual source, artifact and acceptance receipts; pending release fields remain pending until verified.
