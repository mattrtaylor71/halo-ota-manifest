## Setup Instructions

### 1. LVGL Library

Make sure you have LVGL library installed in your Arduino IDE:
- Go to **Tools > Manage Libraries**
- Search for "LVGL" and install it
- Or use PlatformIO with LVGL dependency

### 2. Compile and Upload

1. Open `halomain_assets.ino` in Arduino IDE
2. Select your board (ESP32, etc.)
3. Select the correct port
4. Click **Upload**

### 3. Navigation

- **Scroll**: Rotate the knob left/right to navigate through screens
- **Touch**: Tap on screens to navigate (configured connections)

## Troubleshooting

- **Compilation errors**: Make sure LVGL library is installed
- **Display not working**: Check your board selection and port settings
- **Navigation not working**: Verify knob pins are correct in navigation.cpp
- **'Serial' undeclared errors**: Make sure you have navigation.cpp (NOT navigation.c) - if you see navigation.c, delete it and regenerate the ZIP
- **All files included**: This ZIP contains everything needed - no additional files from other folders are required
