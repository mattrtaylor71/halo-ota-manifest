## Actual failures and plan

1. An early manual input arrived while automatic startup readiness was pending. The handler logged that it joined the existing episode, but returned without retaining manual intent. The automatic due gate subsequently ended that episode without checking the manifest. Preserve one manual intent inside the original readiness deadline; repeated taps must not renew it.
2. A later manual input was accepted while the ordinary wake-triggered shopping-list refresh still owned an operation and HTTP. The strict idle-owner proof correctly refused admission, but the caller treated a temporary busy condition as a terminal postponement. Wait for transient operation/HTTP ownership before entering the transaction, using the same original deadline. Do not wait indefinitely on media held until session sleep: release OTA promptly and retain those uploads.
3. Record a compact, non-sensitive missing-proof mask for any future discovery refusal, so the actual reason is visible instead of only the generic LEGACY result. Preserve the proof conditions themselves.
