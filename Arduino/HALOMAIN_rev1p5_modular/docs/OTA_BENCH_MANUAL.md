# Manual updates in an explicit bench session

`HALO_OTA_BENCH_PROFILE=1` permits the existing bounded manual request to spend a live, explicitly configured test allowance. The request must find a settled `RESOLVED`, `BENCH_ABORTED`, or `BENCH_READY` record, no outstanding arm or reservation, a known writable coordinator ledger without pending legacy debt, fresh clock, current local and peer SDK health, and safe idle ownership. An expired session refuses; it never renews itself.

Use the existing checked `OTA_BENCH configure` transaction to establish a separately authorized session after archiving its exact preimage. Configuration is an external test grant, not production recovery or a refund. Manual discovery retains the session, audit fields, budget origin, and cumulative network/apply/begin charges. It reserves at most the existing 120 seconds, bounded by remaining work, session lifetime, and original invocation allowance, before any manifest GET. A reset retains the debit. A new campaign uses the normal manifest validation, paired coordinator, appliers, and SDK health handling.

With both boards already awake and their current identity verified, the existing LCD `ota` command forwards `INPUT_OTA_CHECK` to the production manual engine. That command does not itself prove physical menu interaction or request the LCD-to-Sense wake handshake. A reason string without the actual bounded manual-input latch does not enable bench discovery.

Repeated successful manual updates consume the same finite session allowance. A verified successful no-update or downgrade-policy check closes in `BENCH_READY`, preserving its observed work charge and cumulative counters without claiming an old target completed. It schedules no automatic poll; another check requires a fresh explicit manual input. A failed or interrupted unbound discovery keeps `DISCOVERY`, the same campaign and session, and the existing bench defer delay. The existing sleep selector, SDK timer, boot queue and coordinator admit its due retry only after fresh clock, current health, known coordinator storage, no legacy debt and safe ownership are rechecked. Each retry commits another cumulative network/work reservation before GET; no calendar rollover or new grant is available. An interrupted reservation keeps its full charge, and its copied old target cannot resolve the unfinished discovery. Bound-target failure retains the existing verified fast arm or deferred retry path. Shipping admission, original scheduled paths, production debt and calendar credit are unchanged. Keep the full production archive for a separately reviewed bench-retirement transition.
